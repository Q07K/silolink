# SiloLink

여러 프로젝트와 AI 도구에 흩어진 기록을 연결하고, 사용 맥락을 바탕으로 조사·학습·프로젝트 운영을 지원하는 CLI·플러그인·데스크톱 제품을 구상합니다.

현재는 제품 방향과 인터뷰·리서치를 정리하는 단계입니다. PRD, 첫 구현 범위와 기술 스택은 아직 확정하지 않았습니다.
