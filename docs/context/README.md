# 이전 맥락과 인계 자료

- 정리일: 2026-11-01, Asia/Seoul
- 위치: [silolink/](silolink/README.md)
- 이전 위치: 저장소 루트의 `silolink-handoff-2026-11-01/silolink/`

기존 인계 패키지 전체를 원래 안내했던 `docs/context/silolink/`로 이동했다. 16개 파일의 이동 전후 SHA-256이 모두 일치하며, 패키지 내부 문서·HTML·출처·검증 기록·매니페스트는 원본 그대로 보존했다.

저장소의 `.gitattributes`는 이 원본 폴더에 한해 줄바꿈 자동 변환과 공백 검사를 해제한다. Git 체크아웃 후에도 매니페스트 지문을 유지하기 위한 설정이며, 원문의 기존 말미 빈 줄도 보존한다.

## 읽는 순서

1. 현재 요구는 [제품 인터뷰 정리](../product/2026-11-01-product-interview.md)와 [제품 방향](../product/2026-11-01-cli-plugin-desktop.md)에서 확인한다.
2. 과거 의도와 판단 과정은 [CONTEXT.md](silolink/CONTEXT.md)에서 확인한다.
3. 유사 제품 조사와 원문은 [RESEARCH.md](silolink/RESEARCH.md), [sources/README.md](silolink/sources/README.md)에서 확인한다.

## 적용 범위

- 패키지의 ‘레포 미생성’, ‘대상 사용자 미확정’ 등은 인계 당시 상태다. 현재 저장소 상태나 최신 인터뷰를 대신하지 않는다.
- 패키지의 `PROMPT.md`는 당시 인계용 시작 문구다. 현재 작업 지시로 자동 적용하지 않는다.
- 원문 스냅샷의 옛 프로젝트 경로와 지침은 역사적 자료다. 현재 저장소의 실행 설정으로 사용하지 않는다.
- `manifest.json`과 `VERIFICATION.md`는 원본 패키지의 지문과 당시 검증 범위를 설명한다. 원문 내부의 옛 경로와 외부 자료의 현재 상태를 검증했다는 뜻은 아니다.
