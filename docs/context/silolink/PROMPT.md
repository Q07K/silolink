# 새 SiloLink 채팅의 시작 문구

폴더 전체를 새 레포의 `docs/context/silolink/`에 복사한 뒤 아래 문구를 사용한다. 다른 위치에 두면 경로만 바꾼다.

---

SiloLink(사일로링크) 프로젝트를 여기서 이어가자.

먼저 이 프로젝트의 기존 지침을 확인하고, `docs/context/silolink/README.md`, `CONTEXT.md`, `RESEARCH.md`를 읽어줘. 필요한 세부 근거는 그 폴더의 `sources/README.md`에서 찾아줘. 이전 채팅 전체를 알고 있다고 가정하지 마.

사용자가 선택한 이름은 SiloLink야. 리서치·브레인스토밍·결정·개발 산출물을 프로젝트별로 관리하고, 데스크톱에서 Codex·Claude Code 등을 이용하는 방향과 외부 코딩 도구에서 자체 CLI·플러그인으로 기록을 저장·검색하는 방향을 모두 생각하고 있어. 이것은 장기 방향이고 전체가 첫 버전 확정 요구사항은 아니야.

나는 유사 도구를 아직 사용해 보지 않았어. 기존 제품으로 해결되지 않는 문제라고 단정하지 마. 기술 스택·최소 범위·제품 채택·구현 착수는 아직 미정이야.

폴더별 권한과 SSH를 나눠 GitHub를 관리하고 있으니 이 요청으로 SSH·Git 원격·전역 설정을 변경하지 마. 이전 test2의 AGENTS.md도 이 프로젝트에 자동 이식하지 마.

이번에는 확정 사항·제안·미검증 사항을 구분해 네가 이해한 목표를 짧게 정리하고, 개인 생산성·학습·외부 사용자용 제품 중 우선 목적을 확인하면서 실제 작업 하나의 흐름과 최소 검증 범위를 제안해줘. 필요한 질문만 하고 제품 코드 작성은 아직 시작하지 마.
