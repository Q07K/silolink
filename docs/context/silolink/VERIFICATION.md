# 인계 자료 검증 결과

기준일: 2026-11-01.

- 원문 Markdown 스냅샷 5개: 원래 파일과 바이트·SHA-256 일치.
- HTML: 인계 폴더를 루트로 같은 원문 재생성 일치·원문 SHA-256·참조 파일 존재 확인.
- 활성 안내 문서와 HTML의 로컬 링크: 폴더 안에서 해석·존재 확인(44개 외부/내부 링크 검사).
- 첫 링크 검사에서 공통 템플릿의 보고서 목록이 패키지 밖을 참조하는 문제를 발견함. 인계 폴더를 렌더링 루트로 사용하고 패키지 안에 보고서 목록을 포함해 재검사 통과함. 공통 생성기와 템플릿은 수정하지 않음.
- 원문 스냅샷 내부의 옛 프로젝트 경로는 역사적 자료로 보존하며 새 프로젝트용 실행 설정이나 활성 링크로 검증하지 않음.
- 화면·모바일·인쇄 렌더링, 새 프로젝트에서의 실제 작업, GitHub 연결·레포 생성·앱 구현은 수행하지 않음.
- ZIP 생성 후 항목과 내용 지문을 별도로 대조함. manifest.json은 자기참조를 피하기 위해 자신의 지문을 포함하지 않음.
