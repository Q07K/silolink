## 유사 제품 조사 — 2026-11-01

- 대화에서 제안한 이름은 Groundwork, 레포명 groundwork다. 레포 생성·이름 충돌 검증은 미실행이며 가칭으로 사용한다.
- GitHub와 공식 제품 자료에서 8개 주요 후보를 비교했다. The Vault는 데스크톱·CLI·MCP·공통 코어와 프로젝트 기록을 제공하는 직접 유사 후보다. Basic Memory는 사람과 AI가 함께 쓰는 Markdown, 프로젝트 매핑, Codex·Claude Code 플러그인까지 겹친다.
- 나머지 후보: Pieces(작업 회상·데스크톱·MCP), projectmem(프로젝트별 개발 기록·CLI·MCP·대시보드), Claude-Mem(세션 자동 기록·회상), Entire CLI(Git 연결 세션·프로젝트 기억), Emdash(데스크톱 코딩 CLI 실행), Open Notebook 및 별도 MCP 서버(자료·노트·대화).
- 조사 후 권고: 전체를 새로 만들기 전에 The Vault·Basic Memory가 실제 사용자 시나리오에서 부족한 부분을 확인한다. CLI 실행 환경은 Emdash도 참고할 만하다. 제품 채택·포크·개발 포기는 결정하지 않았다.
- 차별화 후보: 정형 리서치·브레인스토밍을 근거와 검토 상태가 있는 공유 정리서로 만드는 경험. 경쟁 제품에 없는 기능이나 수요가 검증된 것은 아니다.
- 확인 범위: 원 저장소·공식 문서·일부 릴리스/빌드 구성. 설치·실사용·성능·원문 보존의 직접 검증은 하지 않았다. 라이선스 표시와 유료 서비스 범위도 구분했다.
- 새 프로젝트에서 먼저 읽을 자료: [조사 Markdown](../reports/2026-11-01-groundwork-alternatives.md), [조사 HTML](../reports/2026-11-01-groundwork-alternatives.html). 이전 구상과 의사결정 원문은 그대로 보존한다.
