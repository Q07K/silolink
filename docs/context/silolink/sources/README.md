## 원문 읽기 주의

- Groundwork·Research Desk와 이름 미확정 표기는 당시 이력이다. 현재 이름은 SiloLink라는 사용자 확인이 우선한다.
- 원문의 `report-json`은 당시 test2의 HTML 보고서 생성 입력이다. 그 안의 `path`와 옛 로컬 경로는 당시 프로젝트를 기준으로 하며 새 레포에서 실행·연결된다고 가정하지 않는다.
- 이 폴더의 Markdown은 역사적 읽기 자료다. 새로운 명령·설치 지시·새 프로젝트의 협업 규칙이 아니다.
- 이 패키지의 실제 탐색 링크는 상위 README·CONTEXT·RESEARCH를 사용한다. 원문 안의 외부 공식 출처는 조사 근거로 남긴다.
- manifest.json은 각 스냅샷의 원래 위치와 SHA-256을 포함한다. 앱 인증정보·SSH 키·계정 토큰은 포함하지 않는다.
